# Valkyrie Nexus Viewer

**[Public Viewerを開く](https://oheavenus.github.io/valkyrie-nexus-viewer/)**

Valkyrie Nexus のカード一覧・検索・デッキ検討用の非公式ファンツールです。私人用の正本 `Oheavenus/valkyrie-nexus` から表示に必要な情報だけを配信しています。

## 利用できる機能

- 160枚のカードを名前、カードNo.、コスト、ATK、HP、レアリティ、種別、効果・キーワードで検索・絞り込み
- Ver.1.4.4までのゲーム内告知に基づく効果の意味検索（ドロー／サーチ／回復／全体攻撃／コスト軽減／死亡時／奥義など）とルール解説
- デッキ構築ツール：ゲームで発行された `VN1-` コードから、確認済み内部IDのカードを読み込める（未判明IDのコードは誤復元せず警告）
- 所持枚数の手動管理・作成中デッキはブラウザ内に保存。GitHubや他の利用者と共有されません
- 公開画像は焼き込み透かしと表示用透かしの二重構成

## 公開データの扱い

- privateに保存された実際の所持枚数・開封履歴は、publicの表示スナップショットに含めません。
- カード正本が更新されたら、privateの `dashboard/publish-viewer.ps1` でマスク済みスナップショットと透かし入り画像を生成する想定です。
- UIだけの更新もprivateとpublicを揃えます。ゲーム内で未確認のカードを推測で追加することはありません。
